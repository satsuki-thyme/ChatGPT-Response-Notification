# ChatGPT Response Favicon 1.5.2 レポート

## 状況

1. タブをグループに入れてグループをたたんでいると通知は機能しないようだ。
2. 利用枠回復の通知は回復したであろう時間より10分経過してもなかった。利用状況のページのタブをアクティブにしたら通知が来た。
3. チャットをしているタブで利用枠が回復するとエラーとして通知される。
4. 利用枠回復をエラー通知したタブを開かずに30分待ったが通知はなく正常だった。

## 希望

1. 可能なら通知されるようにしたい。
2. タブが非アクティブでも通知されるようにしたい。
3. エラーとしての通知は避けたい。
4. そのまま。

## 意見

### `3.` について

- 利用枠回復の目印となるなら利用する手もありそう。
  - 複数のタブで回復が観測されてもデスクトップ通知は1回にしたい。

### エクストラ

- プロンプト入力権が戻ってこない現象は `6.1 Sol マックス` で Character Relationship Chart のような重い処理をさせたときに発生している。意図的にエラーを発生させるために無意味な重い処理をさせる指示を教えてほしい。
